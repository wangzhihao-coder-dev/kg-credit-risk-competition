# 基于关联图谱的经营类客户风险预警模型

赛题二“基于应用图谱信息的经营类客户风控模型的构建”的参赛支撑材料。仓库只包含参赛报告实际用到的代码、实验配置与汇总结果。

**参赛报告：** [比赛/reports/参赛报告_经营类客户关联图谱风控模型.pdf](比赛/reports/参赛报告_经营类客户关联图谱风控模型.pdf)

## 项目概要

经营类客户的风险常常先从关联方暴露：上游供应商断供、共享董事的关联企业爆雷、大股东旗下企业接连出事。本项目构建覆盖供应链、董事高管任职与机构持股三类关系，并携带涉诉、延迟披露、财务重述、破产等风险事件时序的企业关联图谱（2015–2023 年，35 个季度快照，278,784 个企业-季度节点），提出“客户编码器 + 关联方编码器 + 非回溯 GraphSAGE”的图神经网络：关联方的风险经两层传导到客户，同时保证客户自身拿不到的市场信息不会经关联方回流，在客户只提供报表与风险事件的条件下，预测其未来 12 个月陷入经营困境的概率。

2021–2023 年时间外测试（测试期完全不参与训练）：

| 指标 | 关联图谱模型 | 不用图谱的同特征模型 | 传统报表评分卡 |
| --- | --- | --- | --- |
| 困境 AP / AUC / KS | 0.086 / 0.857 / 0.593 | 0.081 / 0.834 / 0.541 | 0.071 / 0.842 / 0.549 |
| 每季度复核前 5% 客户，提前覆盖的困境事件 | 35.6% | 34.2% | 32.6% |
| 覆盖一半困境事件所需复核比例 | 9% | 10% | 11% |
| 提前识别的困境企业（按企业去重） | 171 家 | 161 家 | 151 家 |

图谱模型的排序能力显著优于不用图谱的同特征模型（AUC +0.023，95% 区间 +0.013～+0.034），比评分卡多识别 20 家困境企业（区间 2～37 家）。以随机打乱关联关系作对照，AUC 显著更高（+0.011），AP 与之相当；按债务金额计与评分卡相当。完整论证、口径与限制见参赛报告。

## 数据说明

数据来自 WRDS 授权数据库（Compustat、BoardEx、Thomson Reuters 13F、Audit Analytics、CRSP、S&P 评级）。按数据授权协议，原始数据、逐企业明细与模型预测均不包含在本仓库中；仓库只保存代码、固定配置与汇总统计。拥有相应订阅的读者可按 `比赛/experiments/README.md` 重新取数和复现。

## 复现

从仓库根目录运行，Python 3.11：

```bash
uv venv .venv-credit --python 3.11
uv pip install --python .venv-credit/bin/python -r 比赛/experiments/requirements.lock.txt
.venv-credit/bin/python -m unittest discover -s 比赛/tests -v
```

取数、建图、训练与报告生成的完整命令见 [比赛/experiments/README.md](比赛/experiments/README.md)。
